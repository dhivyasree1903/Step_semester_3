# Step Semester 3 - Java Programming

This repository contains the weekly coursework, practical implementations, and assignments for Java Programming across all sessions.

## 📌 Repository Structure & Branching Strategy

This repository follows a feature-branch workflow:

- **`main`**: Production-ready, stable codebase.
- **`develop`**: Central integration branch.
- **`feature/session_1`**: Session 1 - Java Strings & Exception Handling
- **`feature/session_2`**: Session 2
- **`feature/session_3`**: Session 3
- **`feature/session_4`**: Session 4
- **`feature/session_5`**: Session 5
